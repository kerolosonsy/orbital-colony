# Early playtest notes

People the maintainer knew tried Orbital Colony and shared feedback. Two chapter 6 changes in the project's Git history show how that feedback changed the lessons.

| Mission | What players found | What changed |
| --- | --- | --- |
| 6-1 | The lesson had too much text. | The lesson now uses six short steps, one crystal-size walkthrough, an interactive slice exercise, and questions tied to the mission. [Lesson revision](https://github.com/kerolosonsy/orbital-colony/commit/be7976ef3cc0d5d40996aef68e64f2d087677205) |
| 6-4 | The sorting example used unrelated data. A player couldn't tell that `Measure` reads the tile under the drone. | The instructions show where to move and measure. The walkthrough, questions, and hints now use the mission's crystal readings and explain the tick budget. [Lesson revision](https://github.com/kerolosonsy/orbital-colony/commit/5af99f4161954bb08901135f5334ad1ae8176323) |

You can try [First Signal](https://kerolosonsy.github.io/orbital-colony-demo/) in a browser or [install the full game](../README.md#play-locally) to play later missions. If a lesson leaves you stuck, [open a lesson issue](https://github.com/kerolosonsy/orbital-colony/issues/new?template=lesson.yml) with the mission ID, lesson language, and the instruction or example you found unclear.
