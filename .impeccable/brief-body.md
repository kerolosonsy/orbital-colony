Scope: the Orbital Colony game client (web/index.html, style.css, app.js). Mode: Operate.
Audience: anyone learning Go, Arabic lessons with English code, laptop to iPad. Job: read the mission, write Go, run, watch, improve, move on.

## Direction contract
THESIS: Kepler-G is being surveyed. Each mission is one sheet of a planetary geologic survey and your code is what maps the ground. It refuses the dark-IDE-with-neon-glow default every coding game ships.
OWN-WORLD: deep map-ink ground (#17142a) with flat, matte geologic unit colours doing real jobs: regolith ochre, soil rust, ice pale teal, rock slate violet, moss green, crystal magenta, survey red for actions. Hairline neatlines, contact lines between units, stipple and hatch textures drawn in code, cartographic condensed numerals, no glow, no gradients.
STORY: a first-time visitor sees the sheet, the goal and the code within seconds. They run it, watch the drone survey the sheet, and see the quadrangle index fill in as sheets get solved. That index is what pulls them to the next one.
FIRST VIEWPORT: a title-block bar (mission title, sheet code, overall progress, sound, VS Code, reset, Run in survey red). Below it, three work areas: the lesson sheet (RTL), the code editor, and the map sheet with neatline, graticule coordinate ticks, legend and a field-notes console.
FORM: planetary geologic survey map (USGS/NASA unit maps), own list position 1 (pick card), seed 8cdb7629. Signature move: the world drawn as a geologic map with coordinate graticule, and the mission index as a quadrangle sheet index that fills with unit colour. Raises: numbers flip digit by digit; the index is the progress record; plants keep one symbol scale through every growth stage.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
